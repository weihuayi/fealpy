- **适用范围**：fealpy 新网格模块验证任务

本文档用于界定当前 Task 直接建设什么、不直接建设什么，以及与相邻对象如何分界。

## 一、边界定位

本任务为“算例验证任务”，核心目标是验证新 mesh 模块在三维四面体网格下的基础能力，
而非扩展网格模块功能或实现完整网格处理系统。

## 二、纳入范围

本 Task **直接建设**：

- 使用 meshio 读取 `.vtu` 文件
- 提取节点与四面体单元连接关系
- 构造四面体网格数据
- 实现以下计算：
  - 半径比质量指标
  - 四面体单元二面角（6 个）
- 输出统计信息（min / max / mean）
- 提供最小可运行验证脚本

## 三、排除范围

本 Task **不直接建设**：

- meshio 封装层或 IO 框架设计
- 新 mesh 模块底层架构修改
- 网格拓扑操作（flip、refinement）
- 网格优化算法（如 LBFGS、NLCG）
- 各向异性质量度量
- 可视化模块或 GUI 系统
- 自动化测试体系

## 四、相邻对象分界

- 与 A（架构审查）：
  - 本任务不负责结构评审，仅使用现有结构
- 与 C（新网格类型）：
  - 本任务只使用四面体网格，不扩展类型
- 与后续测试阶段：
  - 本任务只完成最小验证，不承担系统测试
