本文档用于界定当前 Task 所要满足的真实问题、真实需求、约束条件与成功条件。

## 一、背景与核心问题

新 mesh 模块需要通过具体算例验证其几何计算与质量评估能力。
当前缺少一个针对三维四面体网格的最小验证路径，尤其缺乏：

- 半径比质量计算验证
- 二面角计算验证

## 二、已确认需求

1. **数据读取能力**
   - 能从 `.vtu` 文件读取节点与四面体单元
   - 数据结构与新 mesh 模块兼容

2. **半径比计算**
   - 正确计算四面体半径比
   - 对 sliver 单元具有敏感性
   - 不出现数值异常（NaN / Inf）

3. **二面角计算**
   - 每个四面体计算 6 个二面角
   - 角度范围在 0° ~ 180°
   - 数值稳定，无异常值

4. **可运行性**
   - 提供完整脚本（读入→计算→输出）
   - 可在独立环境运行

5. **基本验证能力**
   - 至少提供一种验证方式：
     - 正四面体（二面角≈70.53°）
     - 或规则网格测试

## 三、约束条件

- 必须使用新 mesh 模块
- 不修改底层 mesh 架构
- 不引入复杂优化算法
- 允许使用 meshio 作为外部依赖
- 代码应保持简洁、可读

## 四、成功条件

满足以下条件即视为成功：

- `.vtu` 文件可正确读取
- 所有单元均可计算半径比与二面角
- 无数值异常（NaN / Inf）
  - 半径比为理论值
  - 二面角约为 70.53°
- 输出统计信息（min / max / mean）

## 五、待确认需求
