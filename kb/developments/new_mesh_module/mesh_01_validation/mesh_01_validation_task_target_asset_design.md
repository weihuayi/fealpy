# FEALPy | Task Target Asset Design | 新网格模块稳定化验证 目标资产设计

- **版本**：v0.1
- **状态**：草案
- **入库位置**：`kb/developments/new_mesh_module/mesh_01_validation/mesh_01_validation_task_target_asset_design.md`
- **启用条件**：当当前 Task 需要对预期形成的目标资产集合进行统一设计时，本文件必须启用
- **适用范围**：新网格模块稳定化验证任务的目标资产集合设计

本文档用于设计当前 Task 面向的目标资产集合。

## 一、Target Asset 设计范围

明确本任务最终应沉淀哪些可复用资产，以及这些资产分别服务什么职责。

## 二、目标资产清单

- 任务指南
- 架构审查材料
- 算例资产
- 新网格类型资产
- 验证资产

## 三、单资产类型、建议命名与建议入库位置

- 任务指南：
	- 资产类型：Knowledge / Governance Asset
	- 建议命名：`new_mesh_01_validation_task_guide.md`
	- 建议入库位置：`kb/explanation/`
- 架构审查材料：
	- 资产类型：Knowledge / Governance Asset
	- 建议命名：`new_mesh_01_validation_...`
	- 建议入库位置：`kb/developments/new_mesh_01_validation/`
- 算例资产：
	- 资产类型：Code / Knowledge Asset
	- 建议命名：与任务编号直接关联
	- 建议入库位置：`example/` 或 `app/` 下网格相关目录
- 新网格类型资产：
	- 资产类型：Code Asset
	- 建议命名：与新网格类型对象一致
	- 建议入库位置：`fealpy/mesh/` 或其子目录的 schema / storage / view / topology 文件
- 验证资产：
	- 资产类型：Validation Asset
	- 建议命名：可直接回溯验证对象
	- 建议入库位置：`test/`、`kb/developments/new_mesh_01_validation/`，必要时配套 `example/`

## 四、单资产职责

- 任务指南：说明任务目标、分工方式、阅读顺序、输出要求与验证纪律，是本次任务直接交付物。
- 架构审查材料：记录新网格模块中不合理之处、风险点与改进建议。
- 算例资产：证明新网格模块可以完整支撑一个研究主线算例。
- 新网格类型资产：在新架构下实现一种新的网格类型，并可被注册、构造与查询。
- 验证资产：证明算例与新网格类型的正确性、稳定性与可复现性。

## 五、资产关系与接口

- 任务指南为架构审查、算例实现、新网格类型实现与验证活动提供统一执行入口。
- 架构审查材料为算例资产与新网格类型资产提供问题导向输入。
- 算例资产与新网格类型资产共同进入验证资产形成证据。
- 验证资产反向支撑任务指南与后续协作资产迭代。

## 六、验收关注点

- 资产名称与职责是否一一对应。
- 资产是否能被后续成员直接复用。
- 资产是否能支撑后续更大规模的网格迁移工作。
- 资产是否足以作为新网格模块稳定化的基础证据。
