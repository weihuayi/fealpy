# FEALPy | Task Target Asset Design | 新网格模块团队研究工作验证 任务目标资产设计

- **版本**：v0.1
- **状态**：草案
- **入库位置**：`kb/developments/new_mesh_module/mesh_07_module_validation/mesh_07_module_validation_task_target_asset_design.md`
- **启用条件**：当当前 Task 需要统一设计目标资产集合、命名、承载位置、职责、关系、质量关注点与 V&V 接口时，本文件必须启用
- **适用范围**：`mesh_07_module_validation` 的成员记录、缺陷材料、缺陷台账和结果摘要

本文档定义当前 Task 的目标资产集合。目标是让多人产生的结果具有统一字段、稳定路径和原始记录回链，同时避免把未复核问题写成确认 Bug。

## 一、目标资产集合定位

当前 Task 需要同时承载成员级执行记录、问题级复现材料和任务级汇总结果，单一大文件无法清楚区分原始观察、复核状态和汇总结论，因此启用目标资产设计。

所有运行结果默认落在当前目录下；大型、敏感或受限材料不得直接入库，只记录生成方式、脱敏替代物或受控复核位置。

## 三、单资产类型、建议命名与建议入库位置

- `A-01` 只定义成员记录结构，不填写任何成员结果。
- `A-02` 每位成员一份；文件名使用稳定、无空格的 `<member_slug>`，不在多人之间共享编辑同一记录。
- `A-03` 以缺陷编号建目录；优先保存可执行的小型脚本和程序生成输入，避免复制完整研究工程。
- `A-04` 是跨成员聚合入口；原始事实始终回链 `A-02/A-03`，台账只保存摘要和状态。
- `A-05` 在成员记录和缺陷台账完成复核后形成，不复制大段日志。
- `A-06` 只有在缺陷被复现并进入修复时才形成；测试路径以仓库执行时的实际规范为准。

## 四、单资产职责

| 资产编号 | 单资产职责 | 不承担的职责 |
|---|---|---|
| A-01 | 约束记录字段和状态术语 | 不预填通过结论 |
| A-02 | 保存成员原始运行条件、预期、观察、解释和限制 | 不裁定跨成员重复和最终根因 |
| A-03 | 让第三方以较低成本复现具体失败 | 不保存无关的大型输出 |
| A-04 | 聚合问题并维护唯一编号、分类、严重度和回流接口 | 不替代正式 Issue、修复或验收 |
| A-05 | 形成面向 mesh_08 的任务级 V&V 结果接口 | 不隐藏失败、阻塞和未覆盖范围 |
| A-06 | 防止已修复问题回归 | 不替代真实研究场景 Validation |

## 五、资产关系

| 关系编号 | 来源资产 | 目标资产 | 关系类型 | 关系说明 | 使用边界 |
|---|---|---|---|---|---|
| L-01 | A-01 | A-02 | 实例化 | 每位成员复制模板并填写一份记录 | 不删除不适用字段和限制字段 |
| L-02 | A-02 | A-03 | 提取/最小化 | 从真实研究失败提取可复现材料 | 保留原始研究记录回链 |
| L-03 | A-02/A-03 | A-04 | 聚合/去重 | 台账为同一问题分配唯一编号并合并重复报告 | 不覆盖原始观察差异 |
| L-04 | A-02/A-04 | A-05 | 汇总 | 摘要统计覆盖、结果和风险并回链原始资产 | 只使用已标明复核状态的信息 |
| L-05 | A-03/A-04 | A-06 | 回归候选 | 已复现且进入修复的问题转为断言测试 | 由修复或测试承接者实现 |

## 六、质量关注点与 V&V 接口

| 资产编号 | 质量关注点 | 是否需要 V&V | V&V 接口 | 复核要求 | 使用边界 |
|---|---|---|---|---|---|
| A-01 | 字段完整、状态含义清楚、可供不同研究方向复用 | 是 | 文档结构检查 | 模块负责人确认 | 模板完整不表示执行完成 |
| A-02 | commit、环境、命令、预期依据、观察和限制可追溯 | 是 | 成员自查 + 同伴抽查 | 记录提交者确认研究语义 | 只覆盖记录用例 |
| A-03 | 最小、可执行、无敏感数据、能稳定触发观察 | 是 | 独立复现 | 至少一名非报告者复现；无法复现须标记 | 不强求所有问题均已最小化 |
| A-04 | 无静默遗漏、重复关系清楚、分类与严重度有依据 | 是 | 台账复核 | 汇总人和模块负责人复核 | 候选项不写为确认 Bug |
| A-05 | 统计可回算、限制显式、结论强度不越界 | 是 | 与 A-02/A-04 交叉核对 | mesh_08 前人工复核 | 不替代最终验收 |
| A-06 | 修复前失败、修复后通过、断言基于明确不变量 | 是 | pytest 回归测试 | 代码审查与 CI | 后续任务资产 |
