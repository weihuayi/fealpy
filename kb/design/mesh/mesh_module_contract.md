- **启用条件**：当进行架构设计、代码研发、程序测试时，本文件必须启用
- **适用范围**：FEALPy 网格模块

## 一、形状格式

### 1.1 经典低阶形状

**点** `point`

```python
name = "point"
top_dim = 0
OFace = {}
SFace = {}
orientation = [(0,)]
```

**线段** `segment`

```text
0 ----- 1
```

```python
name = "segment"
top_dim = 1
OFace = {
	"point": [[0], [1]]
}
SFace = {
	"point": [[0], [1]]
}
orientation = [(0, 1), (1, 0)]
```

**三角形** `tri`

```text
    2
  /   \
 0 --- 1
```

```python
name = "tri"
top_dim = 2
OFace = {
	"segment": [[1, 2], [2, 0], [0, 1]],
	"point": [[0], [1], [2]],
}
SFace = {
	"segment": [[1, 2], [0, 2], [0, 1]],
	"point": [[0], [1], [2]],
}
orientation = [
	(0, 1, 2), (1, 2, 0), (2, 0, 1),
	(0, 2, 1), (2, 1, 0), (1, 0, 2),
]
```

**四边形** `quad`

```text
3 ---- 2
|      |
|      |
0 ---- 1
```

```python
name = "quad"
top_dim = 2
OFace = {
	"segment": [[0, 1], [1, 2], [2, 3], [3, 0]],
	"point": [[0], [1], [2], [3]],
}
SFace = {
	"segment": [[0, 1], [1, 2], [2, 3], [0, 3]],
	"point": [[0], [1], [2], [3]],
}
orientation = [
	(0, 1, 2, 3), (1, 2, 3, 0), (2, 3, 0, 1), (3, 0, 1, 2),
	(3, 2, 1, 0), (0, 3, 2, 1), (1, 0, 3, 2), (2, 1, 0, 3),
]
```

**四面体** `tet`

```text
     3
   / | \
  /  2  \
 / /   \ \
0 ------- 1
```

```python
name = "tet"
top_dim = 3
OFace = {
	"tri": [[1, 2, 3], [0, 3, 2], [0, 1, 3], [0, 2, 1]],
	"segment": [[0, 1], [0, 2], [0, 3], [1, 2], [1, 3], [2, 3]],
	"point": [[0], [1], [2], [3]],
}
SFace = {
	"tri": [[1, 2, 3], [0, 2, 3], [0, 1, 3], [0, 1, 2]],
	"segment": [[0, 1], [0, 2], [0, 3], [1, 2], [1, 3], [2, 3]],
	"point": [[0], [1], [2], [3]],
}
```

**三棱柱** `prism`

```text
    5
  / | \
 /  |   \
3 ------ 4
|   |    |
|   2    |
|  / \   |
| /    \ |
0 ------ 1
```

```python
name = "prism"
top_dim = 3
OFace = {
	"tri": [[0, 2, 1], [3, 4, 5]],
	"quad": [[0, 1, 4, 3], [1, 2, 5, 4], [0, 3, 5, 2]],
	"segment": [
		[0, 1], [1, 2], [0, 2],
		[0, 3], [1, 4], [2, 5],
		[3, 4], [4, 5], [3, 5],
	],
	"point": [[0], [1], [2], [3], [4], [5]],
}

SFace = {
	"tri": [[0, 1, 2], [3, 4, 5]],
	"quad": [[0, 1, 3, 4], [1, 2, 4, 5], [0, 2, 3, 5]],
	"segment": [
		[0, 1], [1, 2], [0, 2],
		[0, 3], [1, 4], [2, 5],
		[3, 4], [4, 5], [3, 5],
	],
	"point": [[0], [1], [2], [3], [4], [5]],
}
```

**六面体** `hex`

```text
  7 ------- 6
 / |       /|
4 ------- 5 |
|  |      | |
|  3------|-2
| /       |/
0 ------- 1
```

```python
name = "hex"
top_dim = 3
OFace = {
	"quad": [
		[0, 3, 2, 1], [4, 5, 6, 7],
		[0, 1, 5, 4], [2, 3, 7, 6],
		[0, 4, 7, 3], [1, 2, 6, 5],
	],
	"segment": [
		[0, 1], [1, 2], [2, 3], [3, 0],
		[0, 4], [1, 5], [2, 6], [3, 7],
		[4, 5], [5, 6], [6, 7], [7, 4],
	],
	"point": [[0], [1], [2], [3], [4], [5], [6], [7]],
}
SFace = {
	"quad": [
		[0, 1, 2, 3], [4, 5, 6, 7],
		[0, 1, 4, 5], [2, 3, 6, 7],
		[0, 3, 4, 7], [1, 2, 5, 6],
	],
	"segment": [
		[0, 1], [1, 2], [2, 3], [0, 3],
		[0, 4], [1, 5], [2, 6], [3, 7],
		[4, 5], [5, 6], [6, 7], [4, 7],
	],
	"point": [[0], [1], [2], [3], [4], [5], [6], [7]],
}
```
